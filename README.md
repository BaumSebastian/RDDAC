A Python package for accessing and processing the **Real Deep Drawing and Cutting (RDDAC) Dataset** - experimental measurements from sheet metal forming processes.

> **Note:** This dataset and package are currently under development. 

## Overview

RDDAC is the experimental counterpart to the [DDACS (Deep Drawing and Cutting Simulations)](https://github.com/BaumSebastian/DDACS) dataset. While DDACS provides FEM simulation data, RDDAC contains real-world experimental measurements from the same deep drawing and cutting processes.

## Related Projects

- [DDACS](https://github.com/BaumSebastian/DDACS) - Deep Drawing and Cutting Simulations Dataset (32,071 FEM simulations)
